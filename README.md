# The Kotlin Mobile Development Repository

Этот репозиторий создан на GitHub для изучения курса Мобильная разработка на Kotlin" от Samsung Innovation Campus. Здесь будут публиковаться выполненные задачи и проекты из данного курса.

## Описание
- 📚 Репозиторий служит архивом для учебных материалов и практических работ
- 🐍 Основной язык программирования - Kotlin
- 📂 Структура будет обновляться по мере прохождения курса

## Структура репозитория
1. Module 1 - Изучение основ языка Kotlin: функции, Null-безопасность, ООП, наследование, интерфейсы и абстрактные классы, обобщенное программирование в Kotlin, расширений в Kotlin, множеств, списков и ассоциативных массивов.     

2. Module 2 - Изучение операционной системы Android, состава Android-проекта, жизненных циклов активностей, макетов активностей, элементов пользовательского иинтерфейса, многоэлементных макетов активностей, архитектурных компонентов ViewModel и LiveData, элементов пользовательского интерфейса, графических ресурсов, стилей и тем Android приложения, ресурсов для адаптивных макетов, отладки и тестирования приложений.

3. Module 3 - Изучение создания списков элементов с помощью RecyclerView, Binding + RecyclerView, активнотстей и интентов, неявных интентов, работы фрагментов, диалоговых окон, навигации в Android-приложениях, панели инструментов и меню в Android-приложениях, бокового меню в приложениях, вкладок, тестирования пользовательского интерфейса.

4. Module 4 - Изучение многопоточности в Android приложениях, сервисов в Android - назначение и виды сервисов, Bound сервис, определения местоположения устройства, уведомлений (Notification), широковещательных сообщений (Broadcast), приёмников трансляций, создания трансляций, отложенного выполнения действий по расписанию, архитектурного компонента WorkManager, сенсоров, видов сенсоров, обнаружения датчиков.
   
## Цели
1. Систематизировать процесс обучения
2. Сохранять выполненные задания
3. Демонстрировать прогресс в изучении мобильной разработки на языке Kotlin
